# 🔐 Gerador de Senhas Seguras com Interface Gráfica

Projeto desenvolvido em Python com interface gráfica usando Tkinter, ideal para praticar lógica de programação e interface com o usuário.

## 🚀 Funcionalidades

- Geração de senhas aleatórias seguras
- Personalização de critérios (letras maiúsculas, minúsculas, números, símbolos)
- Avaliação da força da senha (fraca, média ou forte)
- Salvamento automático da senha gerada em um arquivo `.txt`
- Interface gráfica amigável

## 🛠️ Tecnologias utilizadas

- Python
- Tkinter (GUI)
- Bibliotecas nativas: `string`, `random`, `re`
